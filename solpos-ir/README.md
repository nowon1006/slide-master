# 솔포스(딥스펙) IR 덱 디자인 시안

솔포스 주식회사 IR 발표자료(원본 25장)의 디자인 시안입니다. 원본 문구와 숫자는 그대로 두고 디자인만 바꿨습니다.

|---|---|---|

| `solpos_IR_E_iso.pptx` | E 아이소 블록: 장마다 남색 면 위치를 바꾸고 입체 큐브 사용 | 1, 2, 5, 6, 12, 21, 23 |

## v2 (slide-master 파이프라인)

`v2_slide-master/` 폴더에 slide-master 워크플로로 다시 만든 7장 시안 3세트(A 글라스 블루, B 아이소 블록, C 라이트 테크)가 있습니다. 자세한 내용은 그 폴더의 README를 보세요.

## 공통 기준
- 내용(문구·숫자) 임의 수정 금지
- 아웃라인 정렬: 좌우 여백 0.6인치, 제목·핵심 메시지·본문·출처 위치 통일
- 선보다 면 위주의 디자인
- 글꼴은 Pretendard, 본문 11pt 이상
- 브랜드 컬러: 솔포스 남색 #1E2188, 보조 블루 #2D5BFF, 딥스펙 노랑 #F1CE36

## 다시 만들기 (`scripts/`)
- 필요 패키지: Node(`pptxgenjs`, `sharp`), Python(`Pillow`)
- `assets.py`: 원본 PPTX의 이미지를 투명 로고·둥근 이미지로 가공합니다. 원본 PPTX를 `../src/`에 풀어둬야 하며, 원본 PPTX는 저장소에 넣지 않았습니다.
- `bg.js`, `bg2.js`: 배경 이미지를 생성합니다.
- `build.js`: 1차 시안, `build2.js`: A·B·C, `build3.js`: D·E를 만듭니다. `assets/` 폴더 기준으로 실행합니다.
