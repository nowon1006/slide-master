# 솔포스 IR 시안 v7 — 참고 PPT의 정렬·배치 방식 적용

사용자가 준 참고 PPT(50장)에서 색과 그림은 빼고 도형·글자 정렬, 배치, 글자 크기 수만 분석해 v6 내용(5장)을 다시 짰습니다. 원본 문구와 숫자는 그대로입니다.

- 상단 포인트 바: 모든 내용 장 맨 위에 파란 그라데이션 띠, 표지는 진한 파랑 전체 배경 + 하단 띠
- 제목: 가운데 정렬(작은 장 표시 16 + 제목 40)
- 내용 묶음: 진한 파랑 머리띠(흰 글자) + 연회색 본문 면으로 한 덩어리씩 완결
- 표·조건 목록: 머리 행과 항목 칸을 면으로 채움
- 핵심 메시지: 하단 파란 띠로 이동
- 글자 크기 4가지(40 / 24 / 20 / 16) — 참고 PPT도 장당 평균 4가지
- 여백 기준: 좌우 80px, 내용 영역 y132–604, 블록 간격 4–16px
